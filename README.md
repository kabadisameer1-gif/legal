# ⚖️ Legal Guide AI — Sovereign Suite

AI-powered legal assistant built with **Python, Streamlit, and Google Gemini AI** to help users understand Indian laws, rights, legal procedures, scams, and legal documents in simple English.

## 📌 Project Overview

**Legal Guide AI** is an intelligent legal support platform designed for educational and informational purposes. It provides plain-English legal guidance, step-by-step legal procedures, document analysis, scam detection, and emergency legal assistance focused on Indian law.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/legal-guide-ai.git
cd legal-guide-ai
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Add Gemini API Key

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```

### 6. Run the Application

```bash
streamlit run app.py
```

Open: **http://localhost:8501**
